📋 COMANDOS RÁPIDOS (Copia y pega):

1️⃣ Instalar EAS CLI:
   npm install -g eas-cli

2️⃣ Login en Expo:
   eas login
   (Usa tu email y contraseña de Expo, o crea cuenta nueva)

3️⃣ Ir a la carpeta del proyecto:
   cd /app/frontend

4️⃣ Generar APK:
   eas build --platform android --profile preview

   ⏱️  Tiempo estimado: 10-15 minutos
   
   Preguntas que aparecerán:
   - Create new project? → Y (Yes)
   - Android package name → (presiona ENTER, ya está configurado)
   - Generate keystore? → Y (Yes)

5️⃣ Descargar APK:
   Al finalizar verás un link:
   https://expo.dev/artifacts/eas/xxxxx.apk
   
   Cópialo y ábrelo en tu navegador para descargar

6️⃣ Compartir:
   Envía el archivo .apk por WhatsApp/Telegram/Email
